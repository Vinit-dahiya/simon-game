## ✨Features

- Random color sequence generation
- Sound effects
- Button animations
- Level progression
- Game over detection
- Restart by pressing any key

## 💻Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- jQuery

## 🚀How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
3. Press any key to start playing.
